一设计系统 Design Tokens

中性灰只用一个色温（冷灰，微蓝调）；全局唯一强调色；正文背景永远不是纯白，文字永远不是纯黑。

强调色选型说明

#5B67C7 是低饱和靛蓝（饱和度约 47%），落在 Linear #5E6AD2 与 Shopify Polaris #5C6AC4 的成熟区间，与冷灰中性色同温。备选：墨绿 #2D7D6E（更纸感）、暖陶 #B65C43（更人文）——只能选一个，全应用锁定。饱和度 >80% 的色块从此在 ColaMD 不存在。

2.3 呼吸感三原则

1. 留白代替分割线——侧栏「文件 / 大纲 / 搜索」分区之间用 20px 空白，不画线。
2. 内容聚拢、边缘放大——正文列宽收窄到 800px，两侧多出的空间就是呼吸感，不要试图填满。
3. 一屏一个焦点——编辑区打开时视野里只应有一件事：文字。侧栏图标、状态栏全部降到 tertiary 色。

四微交互与动效

桌面动效只做三件事：反馈、过渡、层级。没有装饰性动画；一切尊重 prefers-reduced-motion（置 0ms）。

cubic-bezier(0.2, 0, 0, 1)
标准出场（segmented 滑块、浮层位移）——快起缓停
cubic-bezier(0.16, 1, 0.3, 1)
ease-out-expo 系（浮层出现）——更凌厉的减速
场景参数说明
颜色/背景 hover（按钮、列表行、Tab）background-color 120ms ease-out最常用；色变要快
按钮按下background 80ms · 无位移桌面密度下 scale 会晃
浮层出现（菜单/popover）opacity + translateY(-2px→0) + scale(.98→1) · 160ms expo消失 120ms ease-in 仅 opacity
命令面板 ⌘K（建议新增）同浮层 + 内容 stagger 20ms/项Linear 标志性体验
Segmented 滑块transform 200ms cubic-bezier(.2,0,0,1)只动 transform 不动 width
侧栏折叠/展开width 240ms cubic-bezier(.4,0,.2,1)编辑区重排不动画
Tab 激活切换内容 opacity 120ms ease-out不做滑动指示器
文件树展开/收起子树 height 不动画；箭头 rotate 160ms避免布局抖动
保存指示圆点 opacity 160ms；✓ 800ms 后淡出微叙事一次
焦点环0ms 即时 · accent 40% · offset 1px键盘可达性硬要求

五视觉对标分析

抄谁的什么——每一条都映射到本指南章节，不做无出处的「高级感」。

Typora抄「内容的克制」
沉浸式所见即所得 · 750px 窄栏 · 专注模式
  • 正文列宽收窄 + 巨大上下留白 → §3.6 的 800px 居中与 30vh 底部留白
  • 块级 hover 才出现的淡装饰 → §3.6 块级悬停装饰，编辑区默认零杂讯
  • 即时渲染无「预览窗」概念 → 已同源（muya），不加任何编辑态外框
  • 空文档 placeholder 居中上移 → §3.6 placeholder 样式
Obsidian抄「结构与灰阶」
双层侧栏 · 命令面板 · 5 档灰阶暗色
  • 图标 rail + 可折叠面板 → §3.3 备选方案（视图增多时的演进路径）
  • 暗色主题多档灰阶分层（拒绝纯黑一锅烩）→ §1.1b 的 5 档体系
  • Tab 激活即融入内容区 + 未保存圆点 → §3.4
  • 设置弹窗左右分区 + 搜索 → 下一轮设置重构参考
Linear抄「纪律」
键盘优先 · 单强调色 · 低饱和列表态
  • ⌘K 命令面板吃掉 80% 菜单操作 → §3.1 菜单收编的最终归宿
  • 强调色只给「选中/主行动」→ §1.1 accent 使用范围铁律
  • 列表 hover/selected 用 4–7% 透明度，从不实心色块 → §3.5
  • 用留白和字重分层，几乎不用分割线 → §1.3 分割优先级
Bear抄「写作体感」
默认排版即成品的阅读节奏
  • 行距 / 段距 / 标题节奏的阅读体感 → §1.2 prose 行参数直接对齐
