## Recursos

- Visualização em tempo real (WYSIWYG) e interface limpa e simples para uma experiência de escrita sem distrações.
- Suporte a [CommonMark Spec](https://spec.commonmark.org), [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) e suporte seletivo a [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- Extensões Markdown como expressões matemáticas (KaTeX), front matter e emojis.
- Suporte a atalhos de parágrafo e estilo inline para melhorar sua eficiência de escrita.
- Exportação de arquivos **HTML** e **PDF**.
- Vários temas: **Cadmium Light**, **Material Dark** etc.
- Vários modos de edição: **Modo Código-Fonte**, **Modo Máquina de Escrever**, **Modo Foco**.
- Cole imagens diretamente da área de transferência.

#### macOS

Requer macOS 11 (Big Sur) ou superior. Builds universais não são publicados — escolha o instalador `colamd-mac-(arm64|x64)-<versão>.dmg` compatível com a sua máquina.

#### Windows

Requer Windows 10 ou 11. Instaladores x64 e arm64 são publicados — escolha a arquitetura compatível com a sua máquina (`colamd-win-(x64|arm64)-<versão>-setup.exe`).

#### Linux

Baixe o formato que preferir na página de releases: **AppImage**, **deb**, **rpm**, **snap** ou **tar.gz**.

#### Outros

Todos os binários para Linux, macOS e Windows podem ser baixados da [página de releases](https://github.com/TheQYQ/ColaMD/releases/latest). Se uma versão não estiver disponível para o seu sistema, por favor abra um [issue](https://github.com/TheQYQ/ColaMD/issues).
