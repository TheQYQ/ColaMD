# Welcome to ColaMD

A simple and elegant **Markdown editor** focused on speed and usability.

## Getting started

- Type `# ` at the start of a line for a heading
- Wrap text in `**bold**` or `*italic*`
- Use `- ` or `1. ` for lists
- Press `Ctrl+F` to find, `Ctrl+H` to replace
- Toggle source mode from the status bar (bottom left)

## Sidebar

Open a folder via **File → Open Folder…** to browse files in the sidebar.
Under **Preferences → General**, control which files the tree shows:

- Non-markdown files
- Hidden (dot) files and directories
- Custom exclude patterns

## Export

**File → Export** writes HTML, PDF, Word, EPUB, and long-form images (PNG/JPEG).
Pandoc formats (EPUB / LaTeX / RTF / OPML) need the [pandoc](https://pandoc.org) CLI on your PATH.
